# Simple Chess CLI

`python-chess` ライブラリを使った、ターミナルで遊べるシンプルなチェスゲームです。二人対戦だけでなく、ランダムに手を選ぶAI対戦もできます。

## 主な機能

- 二人対戦（同じ端末で交互に指す）
- ランダムAIとの対戦（黒番をAIに切り替え可能）
- UCI形式（`e2e4`, `g1f3`, `e7e8q` など）での指し手入力
- 一手戻す（undo）
- 投了・引き分け宣言
- チェック・チェックメイト・ステイルメイト判定
- 駒不足・50手ルール・スリーフォールド・レピティションによる引き分け判定

## セットアップ

```bash
pip install -r requirements.txt
```

## 遊び方

```bash
python chess_cli.py
```

起動すると、まずAI対戦にするか聞かれます。

```
Play vs random-AI? (y/n) >
```

`y` を入力すると黒番がランダムAIになり、`n`（またはそのままEnter以外の入力）であれば二人対戦になります。

対局中は以下のように指し手をUCI形式で入力します。

```
White move > e2e4
```

### コマンド一覧

盤面表示中、指し手の代わりに以下のコマンドも入力できます。

| コマンド | 動作 |
|---|---|
| `help` | コマンド一覧と入力形式を表示 |
| `resign` | 投了する |
| `draw` | 引き分けを申し出て終局する |
| `undo` | 直前の一手を取り消す |
| `ai` | 黒番のAI操作をON/OFF切り替え |
| `quit` | ゲームを終了する |

## 開発メモ
